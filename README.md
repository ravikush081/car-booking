# Car Booking Website — Flask + SQLite

## Features
- Single-car online booking
- Automatic total price calculation
- Date-overlap protection
- Owner/admin login
- Confirm/reject bookings
- Edit car details from dashboard
- SQLite database

## Run

1. Create a virtual environment:
   `python -m venv venv`

2. Activate it:
   Windows: `venv\Scripts\activate`
   Linux/macOS: `source venv/bin/activate`

3. Install:
   `pip install -r requirements.txt`

4. Run:
   `python app.py`

5. Open:
   `http://127.0.0.1:5000`
